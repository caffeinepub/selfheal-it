# Specification

## Summary
**Goal:** Add account sign-in using Internet Identity for SelfHeal IT.

**Planned changes:**
- Implement a sign-in flow using Internet Identity as the only authentication method.
- Add basic UI states for signed-out vs signed-in users (e.g., sign in/sign out controls).
- Connect authenticated identity to backend calls as needed, without changing immutable frontend hook/component files.

**User-visible outcome:** Users can sign in and sign out of the app using Internet Identity, and the app reflects whether they are currently signed in.
